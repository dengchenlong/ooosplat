# 预览与抽帧控件验证 / Preview and sampling controls

## 本轮行为

- 调整模式透视视图中，编辑结束安全恢复画布焦点及控制器；保留输入、弹窗、选择计算、操作轴、导出和动画隔离。异步焦点票据按预览实例及操作隔离，不用延时聚焦。
- 漫游保持水平、随距离/FOV调整，默认每秒可见高度的15%。本机倍率0.1×–5.0×，步长0.1×；Shift额外三倍。滑轨细化为2px，手柄10px，保留18px操作高度。只在操作提交时保存本机偏好，不逐帧写入、不写项目、不产生撤销记录。
- 抽帧滑轨采用整数索引：0.1%、10%、20%……100%，加上精确FPS默认值及旧比例兼容档。控制值仍为原比例或空值；不改检测、后端校验、自动补帧或生成参数。
- 标题“抽帧比例”使用现有灰色，百分比独立居中；去掉原提示行。自动重试中英文使用本轮确认的文案，不增加自动降级能力。
